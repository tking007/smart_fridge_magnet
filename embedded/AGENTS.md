# 固件分区规范（AGENTS.md）

> 继承根目录 `../AGENTS.md`，本文件只描述固件特有规则。

## 约束

- ESP32 只接收裸像素或文件，不解析菜谱 JSON，不处理中文或 Emoji 排版。
- 规格固定为六色电子纸 792 x 528、`209120` 字节，使用 ESP-IDF v6.0.2。
- 一版四张图片共用一个版本号，整套成功后才推进版本。
- 文件名表达餐次语义；清理时不得删除本轮刚下载并提交的文件。

## 参数与升级

- NVS 参数升级不得清空配网信息、密钥或同步版本。
- 置顶画面使用独立 NVS key，不改变现有参数布局和 `config_version` 语义。

## 验证

- 加载 ESP-IDF 环境后使用 `idf.py build` 构建。
- 真机烧录、串口、按键和网络验证步骤见 `README.md`。
- 引入或修改 FrameFilm 上游代码时保留来源、提交和 GPLv3 许可证信息。
