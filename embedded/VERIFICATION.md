# 固件验证清单

简体中文 | [English](VERIFICATION.en.md)

这是一份公开的硬件验证清单。每次发布候选都应在目标硬件上执行，并把结果保存在项目外的
测试记录中；仓库只保留可复用的步骤和预期行为。

## 构建前

- [ ] `idf.py --version` 为 ESP-IDF v6.0.2。
- [ ] `bash embedded/smart_fridge_magnet/test/host/run_host_tests.sh` 输出
      `ALL HOST TESTS PASSED`。
- [ ] 构建目录、数据库、日志、证书私钥和 APK 未进入 Git。

## 单轮设备验证

- [ ] 冷启动和 FN 唤醒可以打开 BLE 窗口；PREV/NEXT 在醒着时能翻页。
- [ ] BLE 配网要求加密链路，Wi-Fi 密码和设备 Token 不出现在日志中。
- [ ] Wi-Fi 同步使用 HTTPS manifest，设备 Token 正确鉴权。
- [ ] 四张 `.film` 均完成长度、文件头和 SHA-256 校验后才整套提交。
- [ ] 任一下载、校验、刷新或关机失败时保留旧画面，不推进 applied version。
- [ ] 网络同步完成后关闭无线并按策略进入深睡。
- [ ] 断电、重启和恢复出厂后，参数清除范围符合 BLE 协议文档。

## 连续与低功耗验证

- [ ] 连续完成至少 20 次 Wi-Fi 更新，混入无更新和失败轮次。
- [ ] 连续完成至少 10 次 BLE 传输，混入断连或非法帧轮次。
- [ ] 连续轮次后堆水位、任务数和文件句柄没有持续增长趋势。
- [ ] 深睡可由 FN 和 RTC 定时器唤醒；PREV/NEXT 不作为深睡唤醒源。
- [ ] 使用电流表记录唤醒、联网、刷新和深睡电流；不要仅凭串口日志宣称续航达标。

## 结果记录

记录固件版本、ESP-IDF 版本、硬件型号、测试日期、测试轮次、失败注入、关键测量值和回退
版本。不要记录 Wi-Fi 密码、设备 Token、私钥、个人信息或本机绝对路径。
