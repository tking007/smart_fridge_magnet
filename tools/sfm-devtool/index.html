休眠

0x25。sleep_mode 存在 NVS，改固件默认值对已烧录的设备无效，必须显式发一次。

关闭后设备常驻不睡，实测一夜耗尽电池并反复重启，用完请重新开启。

.film 格式

.film = 32B 文件头 + 像素（4bit/像素，2 像素/字节，row-major） 792×528 → 像素 209088 B，总计 209120 B 头：[0..3] 像素长度 = 209088 [4..5] 宽 = 792 [6..7] 高 = 528 [8] 颜色数 = 6 [16..21] 调色板 = 00 FF FC E0 03 1C（真实色值字节，非索引） 像素半字节 = 调色板索引 0..5；固件按 color_lut[colorTable[索引]] 取色，故 colorTable 必须写真实色值。

BLE 契约

Service 0x2000 / Write 0x2001（带响应写）/ Notify 0x2001·0x2002·0x2003 帧：HEAD 0x55 | opcode | len(1B) | payload | 和校验(1B)；len 单字节 ⇒ payload ≤ 255、整帧 ≤ 259 B 一次 BLE 写入 = 一个完整命令包，固件不做跨写入重组 文件传输：FILE_START 0x03 → FILE_NAME 0x00 → FILE_LEN 0x01 → FILE_DATA 0x02* → FILE_STOP 0x04 STOP 成功后固件自动按文件名上屏；不要再发 FILE_DISPLAY(0)（会切回列表第 0 个旧图） 本工具用到的 opcode： 0x05 删除 / 0x06 列表 / 0x07 显示指定 id / 0x45 清空全部 / 0x46 静默接收 / 0x47 按时段显示 0x23 电量 / 0x25·0x26 休眠 设置·查询 0x30 Wi-Fi 开关 / 0x32 SSID / 0x34 密码 / 0x38 连接 / 0x3A 连接状态 / 0x3D 取图状态 0x3E manifest_url / 0x40 device_id / 0x42 device_token（只写）/ 0x43 合并状态 / 0x44 SYNC_NOW 0x48·0x49 唤醒时间表 设置·查询 / 0x4A·0x4B 轮询周期 设置·查询 / 0x4C·0x4D 置顶画面 设置·查询 0x10 OTA_LEN / 0x11 OTA_DATA / 0x13 OTA_STOP 完整表见 embedded/smart_fridge_magnet/docs/ble_protocol.md

发布链路

本工具只做「本地生成 + 蓝牙直传 + 设备参数读写」。 走后端发布用「图片转 .film → 上传到后端」生成的 curl 命令： POST {base}/api/devices/{device_id}/display，Content-Type: application/octet-stream 后端会校验 .film 头（尺寸 792×528、总长 209120）并发布为新版本，设备下次轮询时下载。 菜单渲染、AI 推荐、四张一套的发布都在后端与 Android 侧，不在本工具内重复实现。
